# pair-wise-yf-55 动态表单规则编排和版本迁移模拟器

## 源提示词摘要
业务人员拖拽字段、设置分组、联动条件、计算规则、必填逻辑和多语言文案；发布前模拟旧数据在新结构下的迁移。系统比较版本差异，警告失效规则、循环依赖和引用删除，同时按历史版本解释过去提交的数据。

## 技术栈
React 19 + TypeScript + Vite + MUI + Redux Toolkit + RTK Query + React Router + React Hook Form + Zod + i18next + dnd-kit。

## 已实现闭环
- 表单版本、字段、联动规则和旧数据快照等业务对象。
- 字段拖拽排序、新增字段、添加联动规则、发布新版本。
- 新旧版本差异、旧数据迁移缺口模拟。
- 运行态动态表单、跨字段校验和历史版本解释。
- localStorage 持久化。

## 字段标识版本化（名称与标识分离）
- 显示名称（label）可随时改，字段标识（key）是存储键，二者分开维护；改名称不动标识。
- 真要换标识时登记一条对照（旧标识 → 新标识），发布时冻结进当前版本；旧数据按旧标识兼容读回，历史记录按填写当时那一版解释，之后换名称/标识都不改写旧结果。
- 发布前校验：同一版两个字段换到同一标识、或新标识与已有标识撞车时，发布会停下并指出涉及的字段与对照。
- 标识改动后，引用它的联动提示会同步重算到新标识。
- 两个标签页并发发布：后提交者发现基线已变更会保住草稿、提示重新比对（可点「另一标签页已发布」模拟）。
- 未发布的标识对照随草稿持久化，保存中途断掉后重开仍在，可继续处理直到发布冻结。
